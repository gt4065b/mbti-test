# 💡 WOS 아이디어 뱅크

우송대 교원·직원이 업무 개선 아이디어를 상시 등록하고, 좋아요·댓글을 받은 뒤
AI혁신추진위원회가 격주로 심의해 **정규 WOS 리스트**에 올리는 사이트입니다.
(기획서: 「WOS 아이디어 뱅크 서비스 기획서 v2」, 2026.10.13)

| 홈 | 전체 | 다음 심의 D-일수, 이번 주 인기 3건, 최신·좋아요·댓글순 정렬, 분야·상태 필터, 검색 |

| 아이디어 등록 | 전체 | 필수 5개 + 선택 항목, 비슷한 아이디어 자동 추천, 임시 저장, 연간 절감시간 자동 계산, 실명/익명 |

| 심의 | 운영자·추진위원 | 회차 선택, 내용 확인 대기 목록, 안건 묶음 만들기, 기준별 점수(100점), 결정(등재·보류·미채택)과 사유, 회의록 CSV 내보내기 |
| 관리 | 관리자 | 사용자 역할 부여 |

## 운영 규칙이 반영된 부분

- **7일 규칙**: 심의일 7일 전까지 등록한 아이디어만 안건 대상 (11/5 심의 → 10/29까지 등록)
- **심의 일정**: 11/5, 11/19, 12/3, 12/17, 이후 격주 목요일 자동 계산 (`config.js`)
- **상태**: 의견 수렴 → (운영자 확인) 심의 대기 → 정규 WOS 등재 / 보류 / 미채택, 그리고 병합
- **보류**: 제안자가 '보완하기'로 고쳐 저장하면 심의 대기로 돌아가 다음 회차에 재상정
- **익명**: 화면에는 '익명 제안자', 실제 제안자는 운영자만 확인(`ideaOwners` 컬렉션). 포인트는 실제 제안자에게
- **포인트**: 운영자가 내용 확인(→ 심의 대기)할 때 1회만 지급, 같은 글로 두 번 받지 않음
- **등재**: WOS 번호 자동 부여, 정규 WOS 리스트에 추가, 포상금 내역 기록(금액 미정이면 "금액 미정")
- **병합**: 좋아요(중복 제외)·댓글을 대상 아이디어로 옮기고 원래 글은 '병합'으로 남김
- **결정 기록**: 위원은 점수만 입력하고, 최종 결정과 사유는 운영자가 회의 후 기록합니다
  (익명 제안자에게 포상 내역을 남기려면 실제 제안자를 알아야 하는데, 이는 운영자만 볼 수 있기 때문)

## Firebase 연결하기 (실제 운영)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 선택(또는 새로 만들기) → **웹 앱 추가**
2. **Authentication → 로그인 방법 → Google** 사용 설정
   - **설정 → 승인된 도메인**에 `gt4065b.github.io` 추가
3. **Firestore Database** 만들기 → **규칙** 탭에 `firebase/firestore.rules` 내용을 붙여 넣고 게시
4. **Storage** 만들기 → **규칙** 탭에 `firebase/storage.rules` 내용을 붙여 넣고 게시
5. 웹 앱 설정값(apiKey 등)을 `config.js`의 `firebase: { ... }`에 붙여 넣기
6. 사이트에 학교 계정으로 한 번 로그인한 뒤, Firestore 콘솔에서
   `users/{내 uid}` 문서의 `role`을 `admin`으로 바꾸기 → 이후 **관리** 화면에서 운영자·추진위원 역할 부여
7. '내 활동'의 내 좋아요·댓글 목록은 처음 열 때 브라우저 콘솔에 **색인 만들기 링크**가 나올 수 있습니다.
   링크를 눌러 색인(likes.uid, comments.authorUid · 컬렉션 그룹)을 만들면 됩니다.

> apiKey는 공개되어도 괜찮은 값입니다. 데이터 보호는 보안 규칙(`firestore.rules`)이 담당합니다.

## n8n 알림 (선택)

`config.js`의 `n8nWebhook`에 n8n 웹훅 주소를 넣으면 다음 때 JSON을 보냅니다.

- 안건 묶음을 만들 때: `{ type: 'agenda', round, date, ideas: [{id, title}] }` → 심의 3일 전 위원 메일 발송에 활용
- 결정을 저장할 때: `{ type: 'decision', round, ideaId, title, decision, reason, wosNumber, ownerUid }` → 제안자 알림에 활용

## 파일 구성

```
wos-idea-bank/
├─ index.html          화면 틀
├─ style.css           디자인 (휴대폰 우선)
├─ app.js              화면과 기능
├─ config.js           ★ 운영 설정 (Firebase, 심의 일정, 포인트, 분야)

├─ store-local.js      체험 모드 저장소 (브라우저)

└─ firebase/
   ├─ firestore.rules  데이터 보안 규칙
   └─ storage.rules    첨부파일 보안 규칙
```
